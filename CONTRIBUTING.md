# Contributing Guidelines

Thank you for contributing! Please follow these guidelines to ensure a smooth workflow:

- Use feature branches for all changes.
- Write clear, descriptive commit messages.
- Run `yarn lint` and `yarn test` before pushing.
- Ensure all code is formatted with Prettier.
- Open a pull request for all changes; do not push to main directly.
- Review the README.md for project structure and setup.

For more details, see the README.md and copilot-instructions.md in .github.
